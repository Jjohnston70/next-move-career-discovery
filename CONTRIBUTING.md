# Contributing and source use

Thanks for reviewing Next Move. Source is visible for transparency, inspection, and feedback. **The project's original TNDS code is not currently released under an open-source license.** Ask the owner for reuse or redistribution permission before contributing code or distributing a modified application.

Do not change O*NET Mini-IP activity wording, category mappings, scoring, or its purpose without reviewing the O*NET Tools Developer License and applicable validation conditions. Keep the original 2016 source distinct from original TNDS questions and career exploration ordering.

For bugs, submit steps using fictional data only. Do not attach completed assessments, browser backups, private contact information, client files, or credentials.
