# Security and privacy policy

Do not post a real participant's answers, email, exported report, API token, key, or personal backup to a public issue, commit or discussion. Use only made-up values for troubleshooting and reproducible test cases.

The default standalone app makes no network requests and stores responses in memory. Browser localStorage (if enabled) is **not encrypted**. User-approved exports and email drafts may contain sensitive reflections; the participant controls what is shared.

Report security concerns privately to the project owner through their organization rather than posting exploit details or personal data publicly. There is no hosted email feature, API, account system, or remote database in this release.
